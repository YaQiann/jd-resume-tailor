# JD Resume Tailor

根据职位描述和完整经历库，生成有证据支撑的岗位定制简历。

## 使用

将本目录放入 Codex 的 `~/.codex/skills/`，然后在对话中提供目标 JD 和简历或经历库，并请求使用 `$jd-resume-tailor` 定制简历。

Skill 会匹配岗位要求、选择项目、融合补充素材，并在证据缺失时用示例辅助确认。每个岗位独立维护定稿，可据此生成 HTML 和所需 PDF。
